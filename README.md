# 问卷自动填写助手 Chrome 插件

一款功能强大的 Chrome 浏览器扩展，能够自动检测并填写各种在线问卷表单，支持文本框、单选、多选、下拉框、滑块、星级评分、矩阵题等多种题型，兼容问卷星、腾讯问卷、问卷网、Google Forms 等主流问卷平台。

## 功能特性

### 核心功能
- **一键填写**：自动检测页面上的所有表单字段并填写
- **智能匹配**：根据字段标签（姓名、手机、邮箱等）自动匹配预设答案
- **随机填写**：支持随机模式，适用于匿名调查问卷
- **字段检测**：预先扫描页面，显示所有可填写的字段及类型
- **视觉反馈**：填写完成的字段以绿色高亮显示
- **条件联动**：支持多轮循环检测联动字段并自动填写
- **必填项验证**：填写后检查必填项是否全部完成

### 支持的题型
| 题型 | 说明 |
|------|------|
| 文本输入 | text, email, tel, number, url, date 等 |
| 文本域 | textarea（多行文本） |
| 单选按钮 | radio（单选题） |
| 复选框 | checkbox（多选题/同意条款） |
| 下拉选择 | select（下拉菜单） |
| 范围滑块 | range（评分滑块） |
| 星级评分 | star rating（1-5/1-10星） |
| 矩阵/量表 | matrix table（多行多列评价） |
| 文件上传 | file（自动跳过） |

### 兼容平台
- 问卷星 (wjx.cn / wjx.top)
- 腾讯问卷 (wj.qq.com)
- 问卷网 (wenjuan.com)
- Google Forms (docs.google.com)
- 任意包含 HTML 表单的网页

### 智能匹配字段
- 基本信息：姓名、性别、年龄、手机、邮箱、身份证、地址、城市、生日
- 教育工作：学校、公司、职业、部门、工号/学号
- 个人信息：收入、婚姻、民族、政治面貌、紧急联系人
- 开放问题：建议、意见、备注

### 其他功能
- **多资料管理**：支持创建多套个人资料，按需切换
- **键盘快捷键**：Alt+F 一键填写，Alt+D 检测字段
- **右键菜单**：在页面右键即可快速填写
- **设置页面**：可视化配置个人信息和填写参数

## 安装方法

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 打开右上角的「开发者模式」开关
3. 点击「加载已解压的扩展程序」
4. 选择本插件的文件夹（包含 manifest.json 的目录）
5. 安装完成，工具栏会出现插件图标

## 使用方法

### 基本使用
1. 打开需要填写的问卷页面
2. 点击工具栏中的插件图标
3. 选择填写模式（个人资料 / 随机填写）
4. 点击「一键填写」按钮
5. 等待填写完成，页面右上角会显示填写结果

### 键盘快捷键
- `Alt+F`：一键自动填写当前问卷
- `Alt+D`：检测当前页面问卷字段

## 技术说明

### 框架兼容性
插件使用原生 JavaScript 编写，通过以下技术确保兼容各类前端框架：
- 使用原生 `value` setter 绕过 React/Vue 的值拦截
- 正确触发 `input`、`change`、`blur` 事件
- 支持自定义 DOM 元素（如 Google Forms 的 `role="radio"`）

### 条件联动字段
采用多轮循环填写机制（最多5轮），每轮间隔600ms等待新字段出现

## 注意事项

- 本插件仅用于辅助填写常规问卷，请勿用于作弊或恶意用途
- 部分问卷平台有验证码（如问卷星滑块验证），需手动通过
- 插件不会收集或上传任何用户数据，所有信息保存在本地
